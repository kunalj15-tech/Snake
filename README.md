# 🐍 Snake Game in C++

A classic Snake Game built using C++. This project is part of my journey to improve my C++ programming and problem-solving skills through practical projects.

## 🎮 About the Project

The Snake Game is a console-based game where the player controls a snake, collects food, and tries to achieve the highest possible score without hitting the walls or itself.

## ✨ Features

- Console-based game interface.
- Snake movement in four directions.
- Food generation at random positions.
- Score tracking.
- Wall and self-collision detection.
- Simple keyboard controls.

## 🛠️ Technologies Used

- **Language:** C++
- **Libraries:** iostream, cstdlib, conio.h / unistd.h (depending on platform)

## 🎯 Controls

| Key | Action |
|---|---|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| X | Exit Game |

## 🚀 How to Run

### Linux / Ubuntu (WSL)

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Enter the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Compile the code:

   ```bash
   g++ main.cpp -o snake
   ```

4. Run the game:

   ```bash
   ./snake
   ```
